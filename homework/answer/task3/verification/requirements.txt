代码结构
先了解下代码的运行逻辑。当调用pathtracer时，程序的启动流程如下：
1. 首先main.cpp中的 main() 函数会调用collada/collada.h文件中
的 ColladaParser 函数来解析场景文件，建立网格数据结构和相机及渲染参数。
2. 创建 Viewer 和 Application ，也就是创建主程序类和可视化类。 Viewer 管理底
层 OpenGL 细节和创建窗口，其接收鼠标键盘事件并传递
给 Application 。 Application 创建 pathtracer 进程，包含了相机和场景信
息。
3.  viewer.start() 启动进程，等待GUI各种输入。其中最重要的是启
动 set_up_pathtracer() ，调用 PathTracer::start_raytracing() 。
4.  set_up_pathtracer() 设置了相机和场景，此部分可能对场景构建空间加速结
构，既调用 PathTracer::build_accel() 来设置 BVH。
5. 在 start_raytracing() （在pathtracer.cpp中实现）中，为了并行计算，一般将
场景划分为“图块（tiles）”，组成一个图块队列，由 numWorkerThreads 进行并行处
理。
6. 在队列为空之前，每个线程都会从队列中取出图块并运行 raytrace_tile() 进行
渲染。 raytrace_tile() 调用 raytrace_pixel() 对图块范围内的每个像素进行

渲染。结果保存到pathtracer的 sampleBuffer 中（ HDRImageBuffer 的实例，定
义在image.h）。
你将实现物理渲染器的大部分的核心算法，例如
1. 在 raytrace_pixel() 里面，你将编写一个循环，调用 camera-
>generate_ray(...) 来获取光线，并通
过 est_radiance_global_illumination(...) 获取沿着这些光线的辐射度。
2. 在 est_radiance_global_illumination 中，你将使用 bvh->intersect(...) 判
断光线和场景是否有交点。如果相交，你将返回值光路累积的辐射率 Spectrum
L_out ，光线累积包括两个部分，
在光源直接照射，在， zero_bounce_radiance 里实现 bsdf-
>get_emission() 来获取光的辐射率
在全局光照下，实现 at_least_one_bounce_radiance ，它调用
了 one_bounce_radiance （直接光照函数），并递归调用自身。
在以此核心渲染函数之外，你将实现光线与三角形、球体和包围盒相交的函数、构建和

1.1 生成相机射线（Camera Rays）
请在src/pathtracer/camera.cpp中完成 Camera::generate_ray(...) 函数。
此函数输入规范化（标准化）的图像空间坐标 (x, y) ，输出在世界坐标系（world
space）下的光线 Ray 。这部分需要注意不同坐标系变换，参见lecture 4 Transform，
理解世界坐标到屏幕坐标系之间的一系列变换。此处实现分三步，首先将图像空间的坐
标转换到相机空间，然后在相机空间中生成射线（相机中心和图像坐标的连线），最后
将射线转换到世界空间中。
以相机为中心的相机坐标系如下图所示，相机位于原点 (0, 0, 0)处，相机正面朝向
−Z 轴，该朝向也称为观看方向（Viewing Direction）。
为了模拟相机成像过程，在相机观看方向上，我们定义“虚拟相机传感器”（根据小孔成
像原理，相机的真实传感器在相机观看方向的反方向上，且呈倒立姿态，为了方便理解
和计算，在位于真实传感器的对称位置上定义虚拟传感器，二者成像内容一致，互为倒
立），其为长方形平面，垂直于 Z 轴，具体为Z = −1。传感器的中心位于(0, 0, −1)。

1.2 生成像素样本
请在src/pathtracer/pathtracer.cpp中完成 PathTracer::raytrace_pixel(...) 函数。
与上一节规范化的图像空间坐标不同的是，图像的像素坐标位于非归一化的图像空间
中，为离散数值，和图像分辨率相关。函数输入为像素坐标(x, y)，并在
 sampleBuffer 中更新该像素的辐射度积分结果，对于颜色图，像素有RGB三个通道，
所以积分结果为 Vector3D 对象 ns_aa 。
要估计像素的辐射度积分，应该随机生成 ns_aa 条射线，方法见1.1节
的 generate_ray(...) 。对于每条射线，应调
用 PathTracer::est_radiance_global_illumination(Ray r) 函数来估计该光路的辐
照度，再通过Monte Carlo估计把所有光线进行加权求和，得到 Vector3D 类型的像
素。
采样器简介
采样是图形学课程中的重要概念，lecture 13 Monte Carlo Ray Tracing就是围绕随机采
样来估计辐照度积分结果，本次作业将大量使用这个概念。为此，我们在
src/pathtracer/sampler.h中提供了丰富的“采样器”类，你可以使用它们从给定的分布中
随机采样二维或三维样本。例如， PathTracer 有一个成员变量 gridSampler ，它表示
在正方形区域内进行均匀采样。对于任何采样器类，你可以调用 get_sample() 来得到
一个随机样本。

1.3 射线与三角形求交
请在src/scene/triangle.cpp中实
现 Triangle::has_intersection(...) 和 Triangle::intersect(...) 两个函数。
 Triangle::has_intersection(...) 只是判断三角形和射线之间是否有交
点。 Triangle::intersect(...) 不仅测试交点的存在性，若存在还返回最近的交点的
位置及其他信息。你可以使用lecture 12 Ray Tracing中介绍的任何求交方法来实现。
在课程中，我们以参数化方程来描述射线，参数为t并且仅t ≥0时才是有效的。视锥
的远近可视平面进一步限定了参数的取值范围，其中 min_t 和 max_t 为 Ray 的最小和
最大值，落于期间的交点才是有效的。当计算射线与三角形（和球体）相交时，你将始
终更新 max_t 为最小的值（既最近的交点），而其他比该值大的点将被忽略。
对于 Triangle::intersect(...) ，如果存在有效交点，则将其记录在交点的数据结
构 Intersection *isect 中，该结构体内容如下：
 t 是输入射线与场景的交点对应的参数t的取值。
 n 是交点处的表面法线。因为交点一般不在三角形顶点上，计算三角形内任何一个
点的法线属性，应使用重心坐标对三角形的三个顶点法线的进行线性插值。重心坐
标的计算方法见lecture 5 shading。
 primitive 为指针，其指向与射线相交的图元（使用 this 指针）。
 bsdf 为指针，指向交点处的表面材质（BSDF）（使用 get_bsdf() ）。BSDF 指
Bidirectional Scattering Distribution Function，双向散射分布函数，是 BRDF 的拓
展，同时考虑反射和透射现象。

和球体直接存储在叶节点中。 我们将看到，仅使用简单的启发式方法构建的 BVH 就可
以表现得更好，相交计算的复杂度从O(n) 减小到O(log(n)) 。
2.1 构建BVH
请在src/scene/bvh.cpp文件中完成 BVHAccel:construct_bvh(...) 函数。
BVH 是二叉树。类 BVHAccel 本身只包含根节点 BVHNode *root 。树中的每个节点包
含 (1) 包围盒 bb 、(2) 左子节点 l 和右子节点 r ，以及 (3) 两个STL迭代
器 start 和 end ，分别指向场景图元列表的起点和终点。对于中间节点， l 和 r 为
非 NULL （非空）；对于叶子节点， start 和 end 为非 NULL 。我们通过递归的方式来
构建BVH。
首先，计算图元集合的包围盒，并初始化一个新的 BVHNode 节点，更新其包围盒。当
新节点包含的图元数量小于 max_leaf_size ，则其为叶节点，其左右子节点当为空，
而 start 和 end 迭代器则应适当更新，指向图元列表的正确区间。最后返回此叶节点
并结束递归。

当新节点下的图元数量大于阈值，此时需要将图元划分为“左”和“右”集合。注意，图元
的包围盒存在于3D空间中，我们希望找到最优的轴进行分割，并沿着这个轴计算具体
的分割点，将图元划分为“左”和“右”集合。具体的分割策略可参考lecture 12中介绍的几
种原则和代价计算。对于新创建的左右子节点，分别通过递归调
用 BVHAccel:construct_bvh(...) 函数。当所有子节点为叶节点时，返回BVH树。。
你将使用到的函数如下：
1.  Primitive::get_bbox() 返回图元的包围盒。
2.  Primitive::get_bbox().centroid() 返回图元包围盒的质心。
3.  BBox::expand(...) 扩大包围盒，其根据输入的顶点或其他包围盒，扩大原有的
包围盒以容纳之。输入类型为 Vector3D 或 BBox 。
实现细节说明
分割点，建议采用轴的中点或图元质心的平均值。
如果选择的分割点使得所有图元仅位于分割点的一边，则递归将无限调用，从而出
现段错误。
你可以尝试其他 BVH 构造方法。一些想法包括更改启发式策略（例如，使用图元
集合的中值点等）或改进 BVH 的算法或内存效率。

第 4 部分：全局光照
直接光照的结果整体较为暗淡，因为其仅考虑光源的直接照明，并未考虑间接照明。间
接照明指的是物体表面被光源直接照明后，有一部分比重的光线会散射到环境中，继续
照亮场景中其他地方，这个散射可以一直持续下去。与直接照明的实现过程类似，全局
照明也主要考虑两方面：物体表面材质，也就是反射方程；光线的采样。
4.1 使用漫反射 BSDF 进行采样
在此任务中，你将实现函数 DiffuseBSDF::sample_f 来表示一种漫反射材质，该材质
在半球上向所有方向均匀反射光。
在第3部分中，你实现了 DiffuseBSDF::f ，其输入入射光线的立体角 wi 和出射光线的
立体角 wo ，返回反射率 f(wi -> wo) 。函数 DiffuseBSDF::sample_f 与之有所不
同，它同时需要采样入射光线，它的输入为参数 wo 和指针 wi 和 pdf 。它执行两个任
务：
1.  DiffuseBSDF::sample_f 随机采样入射光线方向，将采样方向结果赋值给 wi ，采
样概率赋予 pdf 。
2.  DiffuseBSDF::sample_f 返回 f(wi -> wo) 。
那么如何对入射光线方向进行采样？请查阅 bsdf.h 文件，你会看到 DiffuseBSDF 包含
一个 sampler 对象。该 Sampler 从余弦加权的半球分布（cosine-weighted
hemisphere distribution）中采样 3D 样本，该概率分布函数在课件中的重要性采样部
分有介绍。
4.2 最多N次反射光的全局照明
对于全局光照任务，你的工作是实现函
数 sample_f 和 at_least_one_bounce_radiance 函数，并完成
src/pathtracer/pathtracer.cpp中的 est_radiance_global_illumination 函数。

 est_radiance_global_illumination 函数估计一个表面点朝特定方向（此方向如
从相机中心朝像素平面投射出来的射线）的总辐照度。其将把零反射照明、一次反
射照明（直接照明）和N次反射照明全部累加。前两者之前已介绍，接下来介绍N
次反射光的全局照明。
 at_least_one_bounce_radiance 函数是第 4 部分的主要工作。此函数会调
用 one_bounce_radiance 函数，判断当前表面点接收到直接光照的数量，然后再
递归调用自身，来计算其他方向的表面点反射到该点的光量。进行递归调用需要新
的顶点和方向，因此需要根据当前点的 BSDF 对某个方向进行一次随机采样，同时
根据当前点和采样方向连成一条射线，在场景中求得新的交点。
如果变量 isAccumBounces 设置为true（默认），那么全局照明将会累
积 max_ray_depth 次反射光。如果设置为false，则将仅返回第 max_ray_depth 次
反弹的光线。例如，如果 isAccumBounces=false 并且， max_ray_depth =2 ，函
数将仅返回第二次反射的光线。此变量用来展示不同光线在经过多次反弹，每次反
弹后余下的光量，能够直观的反应光线传播的衰减程度及光线累积的效果，后面有
具体的渲染图像。
