 cmake ../ 和 make 之间的区别
 cmake 和 make 做完全不同的事情：
 cmake  从项⽬根⽂件夹中的配置⽂件（ CMakeLists.txt ）⽣成⼀个  c++ 项⽬
 make  将项⽬中的所有 C++ 代码编译为⼆进制⽂件。
除⾮您希望更改项⽬结构（例如，添加新库、创建新的  .cpp ⽂件或在调试和发布版本
之间切换），否则每个项⽬ cmake ../ 只需运⾏⼀次。
但是，每次修改代码时都需要运⾏ make ，以重新编译应⽤程序。
使⽤  Ninja 执⾏编译（可选）
构建⼤型 C++ 项⽬时，你可以使⽤ “Ninja” 代替 “Make” 来显着加快重建时间（超过 10

请先安装 ninja ，在 macOS 上执⾏ brew install ninja ，或在 ubuntu-linux 上运
⾏ sudo apt install ninja 。
要使⽤  Ninja ，应将步骤  3 的命令替换为以下命令：
